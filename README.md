# Asad Mulla — Data & AI Portfolio

A responsive, single-page portfolio website built with HTML, CSS, and JavaScript.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `Asad4470.github.io` (if `Asad4470` is your exact GitHub username).
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for deployment and open the site link shown on the Pages settings page.

## Before publishing

- Replace `your.email@example.com` with your professional email address.
- Update each project card's placeholder GitHub link to the exact repository URL for that project.
- Add your LinkedIn and CV links if desired.
- Verify every project description and list only work you can explain and demonstrate.

## Files

- `index.html` — complete self-contained website (HTML, CSS, and JavaScript).
- `README.md` — setup and publishing instructions.
